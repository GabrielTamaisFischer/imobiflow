## Sobre o ImobiFlow

O ImobiFlow nasceu da necessidade real de modernizar a operação de uma imobiliária e reduzir a dependência de sistemas fragmentados. A proposta é acompanhar toda a jornada imobiliária: da entrada do lead e cadastro do imóvel até a assinatura do contrato, vistoria, entrega das chaves e gestão financeira.

Além de centralizar a operação, o projeto explora automações e inteligência artificial para ajudar corretores, gestores, proprietários e clientes a tomarem decisões com mais rapidez e organização.

Este repositório apresenta atualmente a experiência institucional e comercial do produto. A plataforma SaaS completa está em desenvolvimento contínuo.

## Problema que o projeto resolve

Imobiliárias costumam trabalhar com informações distribuídas entre planilhas, portais, mensagens, documentos e diferentes sistemas. Isso pode causar perda de leads, retrabalho, dificuldade para acompanhar contratos e pouca visibilidade sobre o desempenho da operação.

O ImobiFlow foi projetado para reunir esses fluxos em um único ecossistema digital, com dados centralizados e processos rastreáveis.

## Visão do produto

- Centralizar imóveis, proprietários, clientes e corretores
- Organizar leads e oportunidades em um CRM visual
- Automatizar tarefas repetitivas e comunicações
- Digitalizar locações, contratos e vistorias
- Acompanhar indicadores comerciais e financeiros
- Utilizar IA para apoiar atendimento, descrição de imóveis e tomada de decisão
- Oferecer uma presença digital personalizável para cada imobiliária

## Módulos planejados e em desenvolvimento

| Módulo | Finalidade |
| --- | --- |
| CRM imobiliário | Gestão de leads, contatos, funil de vendas, agenda e histórico |
| Gestão de imóveis | Cadastro, fotos, proprietários, disponibilidade e publicação |
| Vistoria inteligente | Vistoria por cômodo, fotos, comparação de entrada e saída e geração de PDF |
| Locação | Contratos, inquilinos, garantias, reajustes, renovações e entrega de chaves |
| Financeiro | Aluguéis, repasses, comissões, inadimplência e fluxo de caixa |
| Site imobiliário | Vitrine de imóveis, filtros, páginas de detalhes e captação de leads |
| Automação | Follow-ups, notificações, tarefas e integrações de atendimento |
| IA imobiliária | Apoio a descrições, análise de leads, sugestões e automação de processos |
| Gestão de equipe | Usuários, permissões, metas e ranking de corretores |
| Auditoria | Histórico de ações e rastreabilidade das operações |

## Como executar localmente

### Pré-requisitos

- Node.js 22 ou superior
- npm

### Instalação

```bash
git clone https://github.com/GabrielTamaisFischer/imobiflow.git
cd imobiflow
npm install
npm run dev
```

Depois, abra o endereço informado pelo Vite no terminal.

### Outros comandos

```bash
npm run build       # Gera o build de produção
npm run preview     # Executa uma prévia do build
npm run lint        # Analisa a qualidade do código
npm run format      # Formata os arquivos com Prettier
```
